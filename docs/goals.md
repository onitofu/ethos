# Цели (Goals) — типы достижений для титулов

Каждый титул привязан к одной цели. Цель определяет, **что** нужно сделать для получения титула. Значение (`value`) определяет **сколько**.

> Статус реализации:
> - ✅ — реализовано
> - ⬜ — не реализовано

---

## `KARMA` — кармические титулы ✅

Автоматически открываются/забираются в зависимости от текущей кармы. Титулы одной стороны (+ или -) сохраняются при росте, забираются при смене знака.

Диапазон кармы: **-10000...10000**. Нейтральная зона: **-1000...1000** (без титула).

### Отрицательная карма

| Диапазон | Титул | Цвет |
|---|---|---|
| -1000...-2000 | Разбойник | gold |
| -2000...-3000 | Хулиган | gold |
| -3000...-4000 | Сталкер | red |
| -4000...-5000 | Головорез | red |
| -5000...-6000 | Каратель | red |
| -6000...-7000 | Безжалостный | dark_red |
| -7000...-8000 | Палач | dark_red |
| -8000...-9000 | Тиран | dark_red |
| -9000...-10000 | Тёмный Лорд | dark_red |
| -10000 | Архидемон | dark_red |

### Положительная карма

| Диапазон | Титул | Цвет |
|---|---|---|
| 1000...2000 | Защитник | green |
| 2000...3000 | Дипломат | green |
| 3000...4000 | Страж | green |
| 4000...5000 | На Кураже | aqua |
| 5000...6000 | Святоша | aqua |
| 6000...7000 | Герой | aqua |
| 7000...8000 | Паладин | light_purple |
| 8000...9000 | Легенда | light_purple |
| 9000...10000 | Избранный | light_purple |
| 10000 | Архангел | light_purple |
