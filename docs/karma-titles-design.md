# Система кармы и титулов — дизайн-документ

## Общее описание

Отдельный плагин. Карма меняется в зависимости от действий игрока (убийства, торговля, мирные действия). На основе кармы и достижений открываются титулы, которые отображаются как префикс в чате. Один активный титул в одном слоте (кармические и ванильные — общий пул).

---

## Система ID титулов

Каждый титул имеет уникальный числовой ID, который **никогда не меняется** после добавления.

### Система звёздочек (★)

Для цепочек с максимальным титулом: после достижения финального титула в цепочке, при выполнении условия повторно (×2, ×3, ...) к названию добавляется звёздочка.

Пример для зомби (ID 204, «Апокалипсис», 1000 убийств):
- 1000 убийств → «Апокалипсис»
- 2000 убийств → «Апокалипсис ★»
- 3000 убийств → «Апокалипсис ★★»
- и т.д.

Звёздочки применяются только к **финальным** титулам в цепочке (с наибольшим порогом). Множитель для повторения = порог финального титула.

ID звёздочных вариантов — тот же ID, звёздочки хранятся как счётчик в данных игрока, а не как отдельные титулы.

### Команды

- `/dt` — список открытых титулов с ID
- `/dt <id>` — установить активный титул (напр. `/dt 801`)
- `/dt info <id>` — подробности о титуле и прогресс
- `/dt reset` — снять активный титул

## Карма

### Диапазон

От **-1000** до **+1000**.

### Действия

| Действие | Карма | Примечание |
|---|---|---|
| Убить враждебного моба | +1 | Базовые (зомби, скелеты) |
| Убить босса (Визер, Дракон) | +50 | Редкие события |
| Торговля с жителем | +2 | За каждую сделку |
| Вылечить зомби-жителя | +30 | Сложное действие |
| Покормить животное | +1 | |
| Убить мирное животное | -3 | Корова, свинья, курица |
| Убить волка/кота (приручённого) | -20 | Чужого питомца |
| Убить жителя | -25 | |
| Убить игрока | -15 | Чтобы PvP не убивал карму мгновенно |
| Убить игрока с положительной кармой | -30 | Наказание за атаку на «хороших» |
| Убить игрока с отрицательной кармой | +10 | Награда за «правосудие» |

> Убийство игрока с отрицательной кармой поощряется — это создаёт динамику «охоты на злодеев».

### Затухание

Пропорциональное: каждый час карма уменьшается на **1% от текущего значения** (округление вниз). Чем дальше от нуля — тем быстрее затухает.

- Карма -500 → теряет ~5 очков/час
- Карма -50 → теряет ~0.5 очков/час
- Карма 800 → теряет ~8 очков/час

Экстремальные значения сложно удерживать без постоянной активности.

## Баффы и дебаффы

Эффекты нарастают с каждой ступенью кармы. Баланс: чем сильнее бонус, тем жёстче штраф.

### Отрицательная карма (путь агрессии)

| Диапазон | Титул | Баффы | Дебаффы |
|---|---|---|---|
| -200...-400 | Разбойник | +5% урон (Strength I, слабый) | Жители повышают цены (на 1 уровень) |
| -400...-600 | Головорез | +10% урон (Strength I) | Жители повышают цены (на 2 уровня) |
| -600...-800 | Каратель | +15% урон (Strength II, слабый) | Жители отказываются торговать |
| -800...-1000 | Тиран | +20% урон (Strength II), +10% скорость | Жители отказываются торговать, железные големы атакуют с 16 блоков, замедленная регенерация здоровья |

### Положительная карма (путь защиты)

| Диапазон | Титул | Баффы | Дебаффы |
|---|---|---|---|
| 200...400 | Защитник | Slow Regen (очень медленная) | — |
| 400...600 | Страж | Regen I, +10% к получаемому опыту | -5% наносимый урон по игрокам |
| 600...800 | Герой | Regen I, скидка у жителей (Hero of the Village I) | -10% наносимый урон по игрокам |
| 800...1000 | Легенда | Regen II, скидка у жителей (Hero of the Village II), Luck | -15% наносимый урон по игрокам, нельзя атаковать первым (PvP cooldown 5 сек после получения удара) |

### Философия баланса

- **Путь агрессии** — сильнее в бою, но социально изолирован. Тиран — машина для убийств, но не может торговать и големы его ненавидят
- **Путь защиты** — лучшая выживаемость и экономика, но слабее в PvP. Легенда почти неубиваема, но не может нападать первым
- **Нейтральная зона** — нет ни бонусов, ни штрафов. Стимул выбрать сторону
- Эффекты нарастают **постепенно**, а не скачком — каждая ступень ощутимо отличается от предыдущей

## Отображение

- **Один** активный титул (кармические и ванильные в общем пуле)
- Игрок выбирает титул по ID: `/dt 801`
- `/dt` — список открытых титулов с ID
- Отображается как **префикс в чате** перед именем
- Интеграция с domya-chat

---

## Обратная совместимость

- ID титула **никогда не меняется** после добавления
- ID титула **никогда не переиспользуется** после удаления
- Новые титулы добавляются с новыми ID в соответствующем диапазоне
- Каждый диапазон имеет запас ~90 свободных слотов
- Если диапазон исчерпан — расширение через x000-x099 (например 2100–2199 для доп. путешествий)

---

## Интеграция с domya-chat

Два варианта:

1. **API-подход** — плагин титулов предоставляет API, domya-chat читает из него
2. **PlaceholderAPI** — плагин регистрирует placeholder `%domya_title%`, domya-chat использует его в формате

Второй вариант проще и стандартнее для Minecraft-экосистемы.
